Workspace File Handling
1.Create a new Pipeline
In Jenkins:
Go to the Jenkins dashboard.
Click New Item: workspace-file-handling
Select Pipeline.
Click OK.
2.Scroll down to the Pipeline section.
Click Pipeline Syntax.
3.Find Sample Step.
Select:
write File: Write file to workspace
4.File:
pipeline.txt
Text:
Created by Jenkins Pipeline
Generate Pipeline Script
writeFile file: 'pipeline.txt', text: 'Created by Jenkins Pipeline'
5.Go back to your Pipeline configuration.
pipeline {
    agent any

    stages {
        stage('Create File') {
            steps {
                writeFile file: 'pipeline.txt', text: 'Created by Jenkins Pipeline'
            }
        }
    }
}
Parameterized Pipeline
1.Create a new Pipeline
Go to Jenkins dashboard.
Click New Item.
Enter a name: parameterized-pipeline
Select Pipeline.
Click OK.
2.Go to Pipeline section
Scroll down to:Pipeline
Select:Definition → Pipeline script
3.Enter the script
pipeline {
    agent any

    parameters {
        string(
            name: 'USERNAME',
            defaultValue: '',
            description: 'Enter your name'
        )
    }

    stages {
        stage('Hello') {
            steps {
                echo "Hello, ${params.USERNAME}"
            }
        }
    }
}
4.Click Build with Parameters
